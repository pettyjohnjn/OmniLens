# Trained-Lens Experiments

## Layout

```
style/lens_style.py     Canonical Matplotlib style. Import it; save via finalize().
                        Enforces the house rules: no titles on top, no bold, one
                        footprint + font scale, one palette. See "Style" below.
figures/                Every regenerated figure (pdf + png). Single output dir.
                        The paper tree is kept in sync from here.
plots/                  Every plot script (one script per figure or figure family;
                        see plots/README.md and run_all.sh). Cross-cutting, so they
                        live together rather than under each experiment.
experiments/            Per-family: run/ (experiment code + PBS), data/ (small result
                        CSVs the plots read), README.md (what it is, how to run).
  01_rank_ablation_estimator/   (+ seed study & RS baseline, 2026-07-18: §6 of its README)
  02_memory_systems/
  03_injection_detection/
  04_memory_injection/
  05_toxicity_dart_toxin/       (+ 8B seed stability, 2026-07-18: §5 of its README)
  06_rank_structure/            (rank truncation vs trained low rank, 2026-07-25)
```

Every CSV/JSON the plot scripts read is copied under `experiments/*/data`, and the
scripts resolve all paths relative to this folder — it is self-contained and can be
copied or handed off as-is.

`fig_method_overview` was generated offline by a diagram script not included in
this release and ships as a static pdf/png; every other figure here is
regenerated by the scripts above. `rank_ablation_exact_kl_1col` and
`fig_finegrained_bars` are regenerated but not embedded in the paper.

Regenerate everything (CPU-only; any Python with matplotlib, numpy, pandas —
the `omnilens` conda env is one that works):

```
cd plots && ./run_all.sh        # or python plot_<name>.py for one figure
```

Outputs land in `figures/` (pdf+png). Finished pdfs are also copied into the
paper tree when that directory exists and is writable; otherwise the copy is
skipped with a warning, so the scripts run fine outside the original account.
